### 4.3 가격 추적과 비교

- 사용자가 확정한 목표는 **한국 기준 Claude Pro 연간 웹과 갤럭시 결제 둘 다 추적해 더 저렴한 경로 알림**이다. 현재 대만 체류나 새 사진만으로 한국 자동추적 목표를 변경하지 않는다.
- `/가격비교등록 클로드 Pro 연간 구독`은 두 경로 생성, 같은 이름 기존 단일 추적 중지, 재등록 중복 방지. 이전 단일 ID ff515973는 미확인 기록이었다. `/가격비교`는 저장값 조회, `/가격확인`은 수동 API 재조회. 일반 `/가격등록 상품명 | 도메인 | 연간·월간·일시불`, `/가격목록`, `/가격중지 ID`, `/가격재개 ID`, `/가격도움말`. 최대10항목.
- DeepSeek POST /v1/tools/search → /v1/tools/fetch 최대3페이지 → /chat/completions JSON 판독. 기본 deepseek-flash, PRICE_WATCH_MODEL로 지정, thinking disabled/max_tokens1800, 페이지당18000자. 검색요약만으로 확정하지 않음. 기존 키 사용. 상품당 검색1/Fetch최대3/모델최대1 과금 가능. 이 기능은 Gemini를 호출하지 않는다.
- 웹 claude.com/claude.ai, Android play.google.com 패키지 com.anthropic.claude 및 gl=KR 검사. iOS/다른 국가/다른 앱 가격 대체 거절. 최초 유효 판매 도메인 유지, 기존 URL 우선. 시장 전체 최저가 보장은 아니다.
- KRW/한국/동일상품/결제기간/일반 구매/구매 가능성과 가격·조건 원문 인용/숫자 검사. 외화 임의환산·월가×12 연간 확정·만료/미래할인·공유계정·제한쿠폰 제외. 세금/배송 주장에는 근거 필요. AI 의미판독 오차 가능.
- 오전 브리핑 성공 후 08<=KST시각<12에 상품별 하루1회. 오후/--print/--balances는 시작 안 함. 잠금/원자 저장, 수집중 중지 반영. 첫 결과/가격·조건 변동 알림, 같은 가격·조건/같은 오류는 생략. 실패시 기존 유효값 보존, 미전송 알림 재시도. 완전한 exactly-once 전달은 보장 안 함.
- 비교 그룹 두 경로 처리 후 묶음 알림. 둘 다 오늘 확인/활성/오류 없음/KRW 연간 총액/세금 포함이어야 승자 판정. 같으면 동일, 한쪽 누락/오래된값/세금 불명은 보류. 카드 추가수수료까지 보장하지 않는다.
- 실제 서버는 두 경로 ‘현재 판매 페이지에서 가격 확인 불가’. 코드상 found/direct_seller 미확인 등의 보류 흐름이다. 서버 원문/실행로그를 직접 본 것은 아니다.

### 4.4 최초 사용자 지역별 가격 화면 — 2026-10-25

사용자는 현재 대만 체류 중이며 **세 번째 사진이 갤럭시 앱 가격**이라고 명시했다. 아래는 사용자 화면의 표시값으로 기록하며 국가설정/최종 결제 통화까지 추정하지 않는다.

| 경로/화면 | 통화 | 월간 | 연간 | 세금·확인 한계 |
|---|---|---|---|---|
| 웹 연간 선택 | TWD(NT$) | 월환산525 | **6,300** | 부가세 포함 명시, 연간17% 절약 표기 |
| 웹 월간 선택 | TWD(NT$) | **630** | 해당없음 | 부가세 포함 명시 |
| 갤럭시 앱 플랜 화면 | INR(₹, 인도 루피) | **1,999** | **21,600** | 연간9% 절약 표기. 월간이 선택된 화면, 연간 옵션 금액은 보임. Google Play 최종결제창/세금 포함 여부는 미확인 |

- 앱의 ₹는 원화 ₩나 대만달러가 아니다. 대만 체류만으로 앱 표시통화도 TWD라고 보지 않는다. 과거 인도 표시 문의 이력과 일치하지만 Play 결제프로필 국가·가격결정 원인은 이 화면만으로 확정하지 않는다.
- 웹 월간을 12개월 유지하면 TWD7,560으로, 표시 연간 TWD6,300은 1,260 절약(약16.7%). 이는 같은 웹 경로의 단순 산술 비교이며 자동추적 코드가 월가×12를 실제 연간 판매가로 쓰는 것과 다르다.
- TWD6,300과 INR21,600을 숫자 크기만으로 비교하지 않는다. 한국 KRW/세금포함 자동비교 조건에도 맞지 않아 기존 추적값을 이 사진으로 덮어쓰지 않는다.
- 앱 연간 선택 후 결제 확정 전 통화·세금·총액 확인이 다음 최소 자료다. 서로 다른 통화 비교를 원할 경우 같은 기준시점 환율로 원화 추정액을 따로 표시하고 실제 카드청구/수수료와 구분해야 한다. 현재 환율조회/환산/구매는 수행하지 않았다.
- 사진으로 확인한 수동 기준값이며 매일 자동 수집 성공 자료가 아니다. 이번 작업 코드 변경/재배포 없음.

## 현재 결정과 다음 행동

- **Claude 공식 웹/갤럭시 결제 비교 작업은 한국 귀국 후 재개**한다. 앱 금액/추가 사진 요청을 당분간 반복하지 않는다.
- 휴대폰/Play 결제 지역이 한국으로 바뀌었는지 서버가 신뢰성 있게 확인하는 연결은 없어 자동 귀국 브리핑 알림은 미구현. 사용자가 재개를 알려준다.
- 작업 보류와 기존 추적 항목 중지는 다르다. 기존 자동 가격 추적을 실제 중지한 증거는 없다.
- 비교 보류/등록 응답 성공과 실제 가격 확보는 구분한다. 사진 기준값은 매일 자동 수집 성공으로 바꾸어 쓰지 않는다.
- Gbuts와 Claude 공식 두 결제 경로 비교는 별개 기능이며, 이번 문서 분리로 코드/타이머/실제 추적 상태를 바꾸지 않는다.
