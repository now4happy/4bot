필수 작업 원칙은 저장소 루트 START.md를 따른다. 아래에서 이번 작업과 관련된 제목만 읽는다.

### 4.1 Gemini 판독 기록

- fanding 첫 판독은 Gemini 우선. 기존 avoid 교차 확인은 다른 제공자 우선 가능. 주문 숫자 검증/교차 확인은 유지했다. DeepSeek의 기존 6장 이미지 실패와 Gemini 성공은 사용자 경험이며 이번에 DeepSeek 이미지 판독 성공을 검증한 것은 아니다.
- 응답 usageMetadata를 JSON 결과 해석 전에 기록, 출력에는 candidate+thinking 토큰 반영. 기록 실패가 기존 판독을 중단하지 않도록 로그 처리. flock/원자 저장.
- AI Studio 사진: 크레딧 $5 두 건, 2026-10-24까지 비용 $0.01. $9.99는 화면 기준 단순 차감 추정액이며 현재 실시간 가용잔액 확정이 아니다.
- `/제미나이잔액 9.99 2026-10-24` 등록 성공(2026-10-25 03:00 UTC). `/제미나이단가 gemini-3.8-flash 0.75 3.75` 및 `/제미나이잔액`도 오류 없이 응답(현지 11:10~11:11). 코드상 저장 후 report 전송으로 저장 성공 흐름과 일치, 서버 상태파일 자체를 읽은 검증은 아니다.
- 서버 모델 확인 명령 출력 gemini-3.8-flash. `.get(...,기본값)` 방식이므로 명시 설정 존재나 실제 호출 성공까지 증명하지는 않는다.
- 공식 문서 https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash 에서 이미지 입력 지원 확인. 2026-10-25 https://ai.google.dev/gemini-api/docs/pricing 기준 Standard 입력 0.75/출력(생각 포함) 3.75 USD/100만 토큰, 2026-12-31까지. 2027-01-01 예정 입력1.50/출력7.50은 적용 전 재확인 필요. 수동 단가는 자동 변경되지 않는다.
- ‘응답 0회’는 기록 기능 설치 이후 포착한 판독 응답 수이며 과거 전체 사용량이나 이미지 장수가 아니다. 여러 이미지를 한 요청에 보내면 응답 1회다. 오류·잔액 부족 표시가 아니다. 현재 평균 비용/잔여 횟수는 실제 기록이 없어 보류가 정상이다.
- 항상 표시되는 단가 등록 도움말은 미등록 경고가 아니다. 다음 정상 판독에서 응답/토큰/비용 누적을 확인한다. 실거래 시험을 유발하지 않는다.
- 비용은 등록 기준액 이후 포착한 토큰×수동 단가의 추정. 다른 프로그램 사용·응답 유실 재시도·청구할인·기준 집계일~등록 전 사용량은 누락될 수 있다. 전체 계정 잔액 자동조회가 아니다. 누락 usage/단가가 있으면 계산 보류.
- 명령: `/제미나이잔액` 조회, `/제미나이잔액 달러금액 [YYYY-MM-DD]` 기준 재설정, `/제미나이단가 모델명 입력단가 출력단가`. 미래/잘못된 날짜, 음수/NaN/무한대 거절.
