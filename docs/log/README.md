# 작업 기록 (docs/log)

여러 AI·여러 기기가 같은 문서를 동시에 고치면 서로 덮어써서 꼬입니다. 그래서 **작업 기록은 작업마다 새 파일**로 남깁니다.

- 파일 이름: `YYYY-MM-DD_AI이름_작업요약.md` (예: `2026-10-28_claude_되돌림감지.md`)
- 한 작업 = 새 파일 1개. 이미 있는 기록 파일은 고치지 않습니다. 틀린 게 있으면 새 기록에 `정정: …` 으로 적습니다.
- 서버의 실제 상태(버전·서비스·적용 여부)는 저장소 맨 위 **STATUS.md** 가 자동으로 보여 줍니다. 여기엔 *왜·무엇을* 했는지만 적습니다.
- 규칙이 바뀌었으면 기록과 별도로 START.md 나 docs/handoff/ 의 해당 항목만 고칩니다.
- 비밀키·토큰·계좌번호는 적지 않습니다.
