# VERIFY — 판 10 (k 규칙 실패 패턴), v0.1.0 (ZIP 파일명 기준)

기준 파일은 Muse 첨부 ZIP의 p_data_v16.json (389행). GitHub 대조는 미확인.

## 실행
```
python3 -I p-verify/15_verify_k_pattern.py p_data_v16.json            # 첫 줄 해시 일치, 내부 점검 17/17, 출력은 p-verify/15_output_v16.txt 와 같아야 함
P10_DATA=p_data_v16.json python3 -I p-verify/16_test_k_pattern.py       # 16개 통과 (P10_DATA 없으면 합성 자료 10개만 돌고 6개 건너뜀)
```
표준 라이브러리만 쓴다. 입력 해시: p_data_v16.json 0a427133b16a9d4e1324d2ea75ac80ae1c815e3378aea8cc8f600a095c5da4cd. 해시가 다르면 첫 줄이 "불일치"로 나오고 종료코드 1.

## 확인한 것
- 입력 해시 대조: p_data_v16.json 0a427133 일치, regen_table_v3_20261111.py b577098b 일치 (첨부 사본 기준).
- 교차: `python3 -I regen_table_v3_20261111.py p_data_v16.json` 의 "보유 중 1번 줄 가격 188/246" = 15_verify의 [9] 188/246.
- 세 실패일(11-16, 11-23, 11-24) 기본가·실제가·k 재현 (47.97/46.97, 42.12/41.12, 31.61/30.37). 10-30 +3.81, 10-26 −3 재현.
- 변조 시험 4개: 가격 변경, 마지막 행 삭제, 11-23 실현수익 변경, 11-16 평단 변경 → 모두 종료코드≠0.
- 결과는 결정적이다 (순열 점검 시드 20261125, 300회). 같은 입력이면 출력 바이트 동일.
