# 📈 토스 스마트 적립(1배 / 1/2배) & 분할익절 자동매매 봇 (`toss_dca_bot`)

## 1. 핵심 매매 규칙 요약
1. **한국 주식(1주 단위 주문) & 미국 주식(소수점 달러 금액/수량 주문) 통합 지원**
2. **내 평균단가(평단가) 대비 현재가 비교 매수**:
   - **현재가 ≤ 내 평단가** (또는 첫 매수): 설정한 1회 기준 금액의 **100% 정상 매수**
   - **현재가 > 내 평단가** (목표 수익률 도달 전): 설정한 1회 기준 금액의 **1/2 (절반) 축소 매수**
3. **목표 수익률(1% ~ 1000% 조절) 도달 시 분할익절 & 이후 매수 금지**:
   - **현재 수익률 ≥ 목표 수익률(기본 +10%, 최대 +1000%)** 도달 시:
     - 보유 수량의 **설정 매도 비율(기본 10% ~ 최대 100%)**만큼 시장가 익절 매도
     - **매수 영구 잠금(`profit_lock = True`)**: 목표 수익률에 한 번 도달한 뒤의 날부터는 신규 매수를 자동으로 멈춥니다. (전량 매도되어 잔고가 0주가 되거나 텔레그램 버튼으로 잠금을 해제하면 다시 적립을 시작합니다.)

## 2. 파일 구조
- `main.py` : 봇 실행 및 일일 자동 스케줄러 오케스트레이터
- `toss_api.py` : 토스증권 Open API 통신 (미국 소수점 주문 / 한국 1주 단위 주문 / 종목·잔고 조회)
- `dca_engine.py` : 평단가 비교 및 익절·매수잠금 판별 코어 엔진 (`dca_config.json` 자동 관리)
- `tg_controller.py` : 텔레그램 버튼 제어반 (`/start`, `/panel`)
