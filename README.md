# 4bot — 개인 자동매매 운영 저장소

이 저장소는 개인 자동매매 봇 5개를 운영하는 코드 저장소입니다.
단일 예제 코드가 아니라, 실제로 매매에 사용하는 봇들의 운영 코드가 들어 있습니다.

## 현재 구성

1. 1번 한투 라오어 — 한국투자증권 API, 미국 주식 자동매매
2. 2번 토스 스나이퍼
3. 3번 토스 스마트적립
4. 4번 빗썸 스마트적립
5. 5번 봇 — 상세 비공개

매매봇 외에 상황판, 브리핑 등 운영을 지원하는 코드도 함께 들어 있습니다.

## 원작자 권리

1번·2번 중 원작을 바탕으로 한 부분의 아이디어와 권리는 원작자에게 있습니다.
원작자가 해당 부분의 공유 중단을 요청하면, 그 부분은 삭제하거나 비공개 처리합니다.

## 면책 조항

이 코드는 특정 투자 전략이나 종목을 추천하거나 투자를 권유하기 위한 것이 아닙니다.
실제 매매에서 발생하는 손실과 시스템 오류에 대한 책임은 코드를 실행한 본인에게 있으며,
어떠한 형태의 수익도 보장하지 않습니다.
